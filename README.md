### Note about contents and use
I make these flashcards for studying the course TDA352 Cryptography. They are based on the keywords from each lecture and the contents from the lectures given during the autumn/winter term 2026.
There is no guarantee of correctness and you are responsible for making sure that the content of the cards reflect the lectures as you have understood them.
You are free to use and edit the cards as you like.

My goal is to make flashcards for the entire course but I will not make any promises that this will happen.

The format is Anki Deck Package (.apkg), intended for use in Anki (https://apps.ankiweb.net/).

To import files:
1. Open Anki
2. click Files > Import (ctrl+shift+I)
3. Choose .apgk file to import
4. Press ok

I keep my cards in one deck per lecture (what you can find in this repo) and all the lectures in a main deck named "TDA352 - Cryptography", which is why the packages are named like they are.
